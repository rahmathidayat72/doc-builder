# Beresin by Satukit — Complete Starter Brand Assets

Isi paket:
- `01_Logo/`: logo utama dan PNG transparan perkiraan
- `02_App_Icons/`: ikon aplikasi SVG, PNG berbagai ukuran, favicon ICO
- `03_UI_Icons/`: 8 ikon SVG fitur (CV, PDF, konversi, foto AI, privasi, offline, kompres, gabung)
- `04_Social/`: Open Graph banner dan square post
- `05_Brand_Guide/`: panduan warna, tipografi, tone, dan penggunaan
- `06_Developer/`: CSS design tokens dan PWA manifest

**Catatan penting:** Logo utama adalah raster dari desain percakapan. Ikon aplikasi dibuat ulang secara sederhana agar scalable. Untuk master SVG logo lengkap yang benar-benar presisi, perlu tracing/desain vector manual.
